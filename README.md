
# AfghanRide

اپلیکیشن آزمایشی درخواست تاکسی آنلاین.

## امکانات نسخه اول
- رابط موبایل‌پسند
- وارد کردن مبدأ و مقصد
- انتخاب نوع موتر
- نمایش نرخ نمونه
- ثبت درخواست آزمایشی

## نصب
این پروژه یک فایل HTML ساده دارد و برای آزمایش به نصب کتابخانه نیاز ندارد.

## انتشار در Vercel
1. وارد Vercel شوید.
2. مخزن GitHub را Import کنید.
3. Framework Preset را روی Other بگذارید.
4. Deploy را انتخاب کنید.

## نسخه بعدی
- دیتابیس آنلاین
- ثبت‌نام مسافر و راننده
- ذخیره درخواست‌ها
- پذیرش سفر توسط راننده
- نقشه و GPS زنده

توجه: نسخه فعلی نمایشی است و هنوز سفر واقعی انجام نمی‌دهد.
